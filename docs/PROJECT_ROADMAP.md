Tous les assistants IA doivent consulter ce document avant toute intervention.

---

# Vision du projet

GH Épaviste n'est pas uniquement un site Internet.

L'objectif est de construire une plateforme professionnelle d'enlèvement d'épaves en Île-de-France répondant aux exigences suivantes :

- excellente expérience utilisateur ;
- performances techniques élevées ;
- référencement naturel durable ;
- accessibilité conforme aux standards modernes ;
- architecture évolutive ;
- maintenance simple ;
- documentation complète ;
- compatibilité avec plusieurs assistants IA.

Toutes les décisions doivent privilégier la qualité sur la rapidité.

---

# Objectifs principaux

Le projet poursuit plusieurs objectifs complémentaires.

## Objectif Produit

Créer le meilleur site d'épaviste en Île-de-France.

Le site doit inspirer immédiatement :

- confiance ;
- professionnalisme ;
- simplicité ;
- rapidité.

---

## Objectif Utilisateur

Permettre à un visiteur de comprendre en quelques secondes :

- les services proposés ;
- les zones couvertes ;
- la gratuité de l'enlèvement lorsque les conditions sont remplies ;
- comment contacter GH Épaviste.

Le parcours utilisateur doit rester simple et évident.

---

## Objectif Technique

Conserver un projet :

- rapide ;
- stable ;
- maintenable ;
- documenté ;
- facilement évolutif.

---

## Objectif SEO

Construire progressivement une forte visibilité locale sans compromettre la qualité.

Le développement SEO doit rester progressif.

Aucune génération massive de pages sans validation intermédiaire.

Le passage à la Phase 6 est autorisé uniquement si :

# Philosophie

Le projet privilégie toujours :

qualité > quantité

cohérence > rapidité

maintenance > complexité

mobile > desktop

expérience utilisateur > nouvelles fonctionnalités

évolution progressive > changements massifs

Chaque amélioration doit rendre le produit plus professionnel sans compromettre sa stabilité.
