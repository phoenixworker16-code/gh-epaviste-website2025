# Objectif

Le fichier DESIGN_AUDIT_TEMPLATE.md définit le modèle officiel utilisé pour auditer la qualité visuelle et l'expérience utilisateur du projet GH Épaviste.

Son objectif est de vérifier que chaque page, composant ou évolution respecte :

• le Design System ;

• l'expérience utilisateur ;

• le responsive design ;

• l'accessibilité ;

• la cohérence de marque.


Un audit doit être réalisé avant toute évolution majeure du design.

# Règles pour les IA


Avant toute modification visuelle importante, une IA doit :


□ analyser l'existant ;

□ respecter le Design System ;

□ éviter les styles improvisés ;

□ vérifier le responsive ;

□ conserver la cohérence de marque.


Une IA ne doit jamais modifier uniquement l'apparence sans analyser l'impact UX.


---


# Principe final


Un bon design n'est pas seulement esthétique.

Il doit être :

• compréhensible ;

• accessible ;

• cohérent ;

• performant ;

• utile à l'utilisateur.


DESIGN_AUDIT_TEMPLATE.md garantit que GH Épaviste conserve une qualité visuelle professionnelle et durable.
