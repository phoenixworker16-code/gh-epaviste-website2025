# Objectif

Le fichier QUALITY_SCORE.md définit la méthode officielle d'évaluation de la qualité globale du projet GH Épaviste.

Son objectif est de mesurer :

• la qualité technique ;

• la sécurité ;

• le SEO ;

• l'expérience utilisateur ;

• la performance ;

• la conformité aux standards du projet.

Il transforme les Quality Gates en indicateurs mesurables.

---

# Philosophie

Un projet professionnel doit pouvoir mesurer son niveau de qualité.

Le principe est :

**Measure. Improve. Repeat.**

L'objectif n'est pas seulement d'obtenir une bonne note.

L'objectif est d'identifier les améliorations nécessaires.

# Méthode de notation

Chaque domaine reçoit une note sur 100.

Le score global est calculé selon les catégories principales.

Une note élevée ne compense jamais :

❌ une erreur critique ;

❌ un problème sécurité ;

❌ une information trompeuse ;

❌ une perte SEO importante.

---

Formule recommandée :

Technique + Design + SEO + Sécurité + UX + Business

# Niveau de qualité

## Elite

Score :

97 - 100

Signification :

Excellence maximale.

Conditions :

✔ aucun problème critique ;

✔ tous les Quality Gates validés ;

✔ amélioration continue active.

## Gold

Score :

90 - 96

Signification :

Produit mature et professionnel.

---

## Silver

Score :

80 - 89

Score :

# Refus automatique

Le score global est refusé si :

❌ problème sécurité majeur ;

❌ perte SEO importante ;

❌ fonctionnalité principale cassée ;

❌ information métier incorrecte ;

❌ régression critique.

# Fréquence d'audit

Audit recommandé :

□ avant Release majeure ;

□ après changement architecture ;

□ après refonte design ;

□ après ajout massif de pages SEO ;

□ après intervention IA importante.

---

# Cas spécifique GH ÉPAVISTE

Les audits doivent surveiller particulièrement :

• pages locales ;

• sitemap ;

• formulaire contact ;

• email ;

• conversion ;

• performances mobiles ;

• conformité métier.

La qualité technique doit toujours servir l'objectif commercial.

---

# Règles pour les IA

Avant de proposer une modification importante, une IA doit considérer l'impact potentiel sur le score qualité.

Elle doit éviter toute modification pouvant réduire :

• SEO ;

• sécurité ;

• performance ;

• conversion.

---

# Validation finale

Un audit qualité validé confirme :

✔ le projet respecte ses standards ;

✔ les risques sont contrôlés ;

✔ les utilisateurs bénéficient d'une expérience professionnelle ;

✔ les futures évolutions peuvent continuer.

La qualité ne doit pas seulement être déclarée.

QUALITY_SCORE.md transforme la qualité de GH Épaviste en un indicateur concret, suivi dans le temps et améliorable.
